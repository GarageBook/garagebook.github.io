# Analytics Events

## `cta_click`

Verzonden wanneer een bezoeker op de marketingsite klikt op een link naar `https://app.garagebook.nl/` of `https://app.garagebook.nl/start`.

Gemeten velden:
- `cta_url`
- `cta_text`
- `page_path`
- `page_title`
- `source` met vaste waarde `marketing_site`

Er worden geen persoonsgegevens meegestuurd. De tracking loopt centraal via [script.js](/mnt/raid1/GarageBook/Website/GarageBook/script.js).
